**ISO image builds**:

We certify our images using SHA256 and take them from [GitHub]([https://os.b1ack.net/deb](https://github.com/b1-ack/operating-system)), even on the official website.
We've fully opened up the ISO image build process with all the necessary configurations on GitHub, and we've also included instructions on the [GitHub Wiki](https://github.com/b1-ack/operating-system/wiki/How-Build-Custom-ISO).

The official image comes without an interface, only the base system with drivers, a fish terminal, archivers, repositories, and file and network systems. Additionally, on our website we also provide an ISO with Cinnamon pre-installed. However, you can use fan builds from the Telegram forum, provided you've verified their safety.

**Repository**:

The system uses official [Debian](https://deb.debian.org/debian) repositories with additional settings for availability, freshness, and compatibility. For similar purposes, we also have our [own](https://os.b1ack.net/deb) open, moderated repository, which prioritizes maintainers from official software developers or those close to them.
By default, the repository is scheduled to update every second day, but we try to publish patches and new releases on the same day they're ready.
